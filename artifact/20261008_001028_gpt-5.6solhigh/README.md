# GPT-5 初赛答案（2026-10-08 00:10:28）

本版本按题目文档实现确定性基线：TXT/XLSX 解析、字段归一、跨源加权关联、文本一致性检查、雷达异常与核心海域门控、跨日主线追踪，以及 8 个节点的 DOCX/XLSX/PNG 输出。

## 运行

```powershell
python -m pip install -r requirements.txt
python solution.py --input "..\..\赛题2-初赛\数据" --output "output"
```

可用 `--nodes 2025.5.10` 只生成一个节点。全部中间证据位于 `output/中间结果/evidence.jsonl`，每行保存事件字段、三源文件定位、匹配分数、纳入/排除结论和理由。`output/validation.json` 是交付结构自检结果。

## 核心口径

- 文件编号不参与关联。
- 开源军情和网上舆论均须达到字段支持阈值，且两类文本标题一致度不低于 0.30。
- 只纳入东海、南海、黄海核心区域。
- 经纬度越界等明显雷达异常直接排除。
- 节点报告只使用节点日信息；第二节跨日主线只读取节点日及以前数据。

这是可运行的规则基线，不调用外部模型或网络，便于复现。赛前建议根据官方隐藏评测样例校准别名词典、时间连续性和冲突阈值。
