# 日报交付格式与文件规范

## 1. 提交目录

```text
日报/
└── 2025.5.10/
    ├── 2025.5.10日报.docx
    ├── 2025.5.10机舰活动明细.xlsx
    └── 附件图表/
        ├── 01_舰机侦巡数量曲线图.png
        ├── 02_中国主要机舰活动示意图.png
        ├── 03_美国主要机舰活动示意图.png
        └── 04_其他国家主要机舰活动示意图.png
```

每个指定节点应形成对应的一套 DOCX、XLSX 和 4 张 PNG，不提交 PDF。提交 ZIP 可在 `日报/` 下包含全部指定日期目录。

## 2. DOCX 内容

标题固定为“{月}月{日}日飞机舰船活动情况”，并包含：

1. 当日活动总览；
2. 一、重要军事动向；
3. 二、重点态势分析；
4. 三、外（台）机舰活动情况；
5. 四、美重要武器平台部署情况；
6. 五、次日关注重点。

正文应明确区分核实事实与分析性推断，并引用必要的统计和证据关系。

## 3. XLSX 规范

文件名为“{日期}机舰活动明细.xlsx”，且只允许两个工作表：`飞机`、`舰艇`。

飞机表固定 16 列：日期、星期、国家地区、机型、批号、批次、架次、起飞基地、呼号、起飞时间、降落时间、活动方向、活动区域、任务描述、任务类型、备注。

舰艇表固定 11 列：日期、国家地区、舰船、批号、艘次、活动时间、活动方向、活动区域、任务、母港、备注。

不得增加内部工作表或自定义列。字段名、列顺序、数据类型和单位应与官方示例一致。

## 4. PNG 规范

4 张图均应为可正常解析的 PNG，包含完整图题、图例、坐标、单位，且正文中应有对应引用。图表数据必须来自节点当日可信事实。
