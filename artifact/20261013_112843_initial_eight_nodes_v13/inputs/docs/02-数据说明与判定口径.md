# 数据说明与判定口径

## 1. 目录结构

```text
数据/
└── 2025.5.1/
    ├── 开源军情/*.txt
    ├── 网上舆论/*.txt
    └── 雷达信息表_2025.5.1.xlsx
```

TXT 使用 UTF-8 编码，XLSX 包含“飞机”和“舰船”工作表。

## 2. 数据用途

| 来源 | 主要内容 | 用途 |
|---|---|---|
| 开源军情 | 抄收时间、发文时间、标题、正文、主题词 | 事件经过、平台、区域和行动线索 |
| 网上舆论 | 时间、标题、正文 | 报道视角、反应和补充事实 |
| 雷达信息表 | 飞机、舰船观测记录 | 平台、时间、位置、任务、数量和轨迹核验 |

## 3. 三源核验原则

候选事件只有同时满足以下条件，才能作为可信事件纳入日报：

1. 三类来源能够关联到同一事件；
2. 关键事实至少获得两类来源支持；
3. 第三类来源没有提供无法消解的明确冲突；
4. 雷达记录只能作为核验依据之一，不具有无条件优先级。

无法完成交叉核验或关键冲突无法消解的事件不纳入标准日报。

## 4. 活动方向归一化

| 方向 | 代表区域 |
|---|---|
| 东海 | 东海、钓鱼岛海域、赤尾屿海域、上海外海、长江口外海、舟山外海、冲绳海槽、苏岩礁附近海域等 |
| 南海 | 南海、北部湾、琼州海峡、东沙、西沙、中沙、南沙、黄岩岛、美济礁、仁爱礁、万安滩等 |
| 黄海 | 黄海、北黄海、南黄海、青岛外海、成山头外海、海州湾外海、济州岛西部海域等 |
| 其他 | 台湾海峡、巴士海峡、巴林塘海峡、宫古水道、对马海峡及未列出的区域 |

通行区域只有在材料明确表明平台进入或离开三大核心海域时，才计入对应核心海域事件。

## 5. 雷达异常类型

重点识别位置漂移、时间异常、区域错配、轨迹跳变、数量异常、任务异常及主体—平台错配，并结合时空连续性和其他来源判断是否为噪声。
