# 正式文件模板执行约定

参考：仓库根目录提交示例文件/日报/2025.10.20/2025.10.20日报.docx及同名明细XLSX。参考文件保留只读，实际哈希与结构见evidence/sample_structure.json和qa/sample_renderer.json；全文Office导出为13页，qa/sample_docx/保存逐页图。

页面：A4纵向，21.00086×29.70036cm，页边距上3.70064、下3.50132、左2.80106、右2.59997cm，单节。继承示例的样式、段落属性与页码页脚；采用v12已改善的正文16pt、标题22pt、黑字。标题和一至五章节使用示例段落角色，正文保留首行缩进与行距。输出长度由实际内容决定，不压缩正文来凑页数。

编辑槽：标题；当日总览；一、重要军事动向；二、重点态势分析及证据索引；三、外（台）机舰活动；四、美重要平台；五、次日关注；四张附图。复制示例的实际段落属性并扩展正文槽。全部10月示范事实、附件5/6基地点名表和未引用的示例图片有意删除；不进入初赛输出。其他章节只写节点当日，分析槽才容纳5月1日至节点历史。

保留范围：页面几何、样式、编号及页码结构；素材引用由本轮四张图重新建立。只允许本轮当前数据与已审阅分析进入正文，旧报告文本不加载。正文引用F对应当日记录，H对应完整主线，R对应两份实际已读固定历史原件。

XLSX：只有飞机、舰艇；表头逐字按示例（含起飞换行基地），16/11列；日期、批号、时间为文本，批次/架次/艘次为数字。未知辅助字段留空。单源地点只存审计。采用宋体11pt，完整换行，冻结表头与前三列，合理加宽型号/任务/备注。

PNG：四个规定名称，白底、黑字、浅灰网格；红圆/蓝方数量曲线，橙色飞机/蓝色舰艇时段横条。曲线24个整点为核实窗口参加量，非总出动；不造精确坐标或航路。图例置图框外，长平台名换行，晚间标签向左放置。

完成门槛：8DOCX全文真实渲染且逐页检查，8XLSX所有填充区域渲染，32PNG全部检查；结构、成员、内容数值、引用与哈希另由独立解包路径校验。图像检查不证明语义真值或平台成绩。
