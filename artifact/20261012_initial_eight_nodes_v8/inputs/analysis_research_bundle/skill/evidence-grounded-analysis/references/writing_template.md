# 分析正文模板与案例用法

## 通用论证模板

总体判断：在[时间范围]内，[已核实事实]支持[有限判断]。相比[同口径基线]，变化主要体现为[有证据支持的维度]；[更强解释]尚缺少[具体证据]。

分阶段：按输入中的真实证据日期划分2—3阶段。每阶段说明相对于前一阶段改变了什么、没有改变什么，以及依据，不重复堆砌主体名称。日期缺失不能自动补齐。

外部背景：[机构]在[公开日期]发布的[具体材料]说明[事实/观点]，统计范围为[范围]、单位为[单位]。它对本节的作用是[提供基线/补足背景/约束解释]，不能证明[超出原文范围的事情]。

替代解释：[另一种解释]也能解释部分现象；当前证据对两种解释的区分能力为[具体说明]。缺少资料时不要作确定性选择。

结论：保留[支持充分的结论]；对[不足部分]不作扩展。

## 从案例中学习什么

SCSPI年度报告（E01）：只学习先给总体判断，再围绕不同主题组织统计和解释的结构；不把该文观点作为当前事实。

AMTI年度回顾（E02）：只学习定义统计口径、说明观测覆盖限制以及克制解释数据变化的写法；不迁移单位级轨迹。

ODNI年度报告（P01）：学习把资料截止日期、评估范围放在前面。不要把某方威胁评估当成中立事实。

## 避免的写法

弱：资料显示活动很多，说明局势复杂，值得关注。

改：材料中的记录数与独立事件数尚未区分，因此不能用前者直接衡量活动规模；本节仅报告已完成去重且有证据定位的变化。

弱：某平台通常承担某任务，所以本次一定执行该任务。

改：一般用途只能说明能力背景；本次实际任务以输入的可核实证据为准。

以上都是写作示范，不包含可作为事实引用的新案例。
