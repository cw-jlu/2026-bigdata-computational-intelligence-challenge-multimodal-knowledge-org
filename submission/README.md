# 两版初赛答案

本目录提供两个独立 ZIP：`GPT_初赛答案.zip` 和 `Claude_初赛答案.zip`。每个 ZIP 都包含 8 个研判节点，解压路径为 `日报/<日期>/`，每个日期目录内有 1 份 DOCX、1 份 XLSX 和 `附件图表/` 下的 4 张 PNG。ZIP 文件名采用 UTF-8 编码，中文路径可正常解压。

两个 ZIP 分别取自仓库内原有的 GPT-5.6 和 Claude Opus 5.5 成果，保留各自的报告、明细与图表内容，仅调整打包路径。`build_submissions.py` 验证文件清单、DOCX 标题与章节、XLSX 工作表及表头、PNG 格式、嵌入图数量、ZIP CRC 和解压后的文件可读性。`manifest.json` 列出 SHA-256、大小、节点明细行数和正文附图引用检查结果。

**已发现的合规差异：**Claude 版 8 份 DOCX 均有明确的“附图1—4”引用；GPT 版 8 份 DOCX 均嵌入 4 张图并列出附件文件名，但没有在正文中显式写“附图1—4”。如平台严格检查正文引用，GPT 版可能因此扣分。仓库没有官方 XLSX 提交样例，所以已核对工作表、列名和列顺序，但无法证实数据类型及单位与未提供的官方样例完全一致。

**初赛评分记录：**参赛者提供的 `initial` 赛程结果显示，两版各评测 8 个节点；Claude 的完整性、准确性、格式、分析分别为 `96.7004`、`19.8215`、`80.2587`、`44.1250`，加权总分 `52.9675`；GPT 分别为 `83.2458`、`17.8993`、`73.3715`、`25.3750`，加权总分 `44.0519`。权重、计算方式及结果说明见[评测标准与复现清单](../docs/05-评测标准与复现清单.md)。原始逐节点分数和平台记录尚未归档，也没有独立人工事实真值验证。

在仓库根目录重建：

```powershell
python -m pip install -r artifact/20261008_001929_claude-opus-5.5high/requirements.txt
python submission/build_submissions.py
```
