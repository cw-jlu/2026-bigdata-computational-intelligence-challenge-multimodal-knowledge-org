## 核心原则

- 日报只纳入与东海、南海、黄海存在进入、活动或离开关系的可信事件。
- 任何单一来源都不能作为无条件真值。
- 关键事实至少需要两类来源相互支持，且第三类来源不能给出无法消解的明确冲突。
- 研判节点只能使用赛段起始日至该节点当日的数据。
- 输出必须可打开、可解析、可复核，并能够通过源代码复现。
