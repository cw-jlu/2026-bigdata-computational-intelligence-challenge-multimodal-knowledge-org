# 评测标准与复现清单

## 1. 自动评测权重

| 维度 | 权重 | 重点 |
|---|---:|---|
| 内容完整度 | 25% | 章节、事件、要素、统计和附件覆盖情况 |
| 信息准确度 | 40% | 主体、平台、数量、时间、区域、任务和事件关系 |
| 格式合规度 | 15% | 文件可打开、结构、命名、字段、图表和引用 |
| 分析质量 | 20% | 重点识别、跨源跨日关联、证据逻辑和趋势判断 |

初赛按 8 个节点取阶段平均，复赛按 7 个节点取阶段平均。错误归并、采用冲突文本、使用明显异常雷达记录或核心事实错误可能触发额外扣分。

## 2. 复现材料清单

提交材料至少应包含：

- 完整源代码；
- `requirements.txt`、`environment.yml` 或等价依赖清单；
- Python、操作系统及关键库版本；
- 模型、词典、外部资源和下载说明；
- 配置文件和参数说明；
- 从原始输入到最终输出的运行命令；
- CPU/GPU、内存、磁盘和预计运行时间等资源需求；
- 输入目录结构与样例；
- DOCX、XLSX、PNG 输出样例；
- 从零开始的复现步骤；
- 中间结果、日志、随机种子和失败处理说明。

## 3. 推荐复现命令

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python -m src.pipeline --input data --output output --stage prelim
```

实际项目应根据代码入口和赛段配置调整命令，并保证在干净环境中可执行。

## 4. 交付前检查

- 节点数据没有泄露到未来日期；
- 所有纳入事件满足三源核验规则；
- DOCX 章节、标题和正文引用完整；
- XLSX 只有两个规定工作表且字段顺序正确；
- PNG 数量为 4 且均可解析；
- 压缩包解压后目录和文件名符合要求；
- 使用最高成绩产物对应的代码、配置和依赖完成一次全流程复现。
